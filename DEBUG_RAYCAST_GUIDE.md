# 🎯 Debug Raycast - Инструмент тестирования коллизий

## Что это?

Система для визуального тестирования серверных коллизий в реальном времени.

**Как работает:**
1. Клиент отправляет raycast от камеры на сервер каждые 0.3 секунды
2. Сервер проверяет коллизию и возвращает точку попадания
3. Клиент показывает **красный кубик** в месте попадания

---

## Установка

### В Unity Editor:

1. **Откройте сцену Game**
2. **Найдите GameObject "Player"** (или создайте пустой GameObject)
3. **Add Component → DebugRaycast**
4. **Настройте (опционально):**
   - `Enable Debug`: ✓ (включить при старте)
   - `Raycast Interval`: 0.3 (частота проверок в секундах)
   - `Raycast Distance`: 100 (максимальная дистанция)
   - `Debug Marker Prefab`: (оставить пустым - создаст кубик автоматически)
   - `Player Camera`: (автоматически найдёт Main Camera)

---

## Использование

### Запуск:

1. **Запустите сервер** (ServerShooter)
2. **Запустите игру** в Unity
3. **Подключитесь к серверу**
4. **Смотрите на объекты** - красный кубик будет показывать точку коллизии

### Управление:

- **F3** - Включить/Выключить debug режим
- Кубик автоматически следует за вашим взглядом

### Что показывает:

**Красный кубик виден:**
- ✅ Коллизия работает
- ✅ Сервер детектирует поверхность
- ✅ Точка попадания правильная

**Красный кубик НЕ виден:**
- ❌ Нет коллизии (смотрите в пустоту)
- ❌ Или коллизия не работает на этом объекте

## Тестирование ракет

Теперь можно **визуально проверить**, почему ракета пролетает сквозь стены:

### Тест 1: Толстая стена
1. Смотрите на толстую стену (пол, большой объект)
2. **Видите кубик?** → Коллизия работает
3. **Не видите?** → Проблема с mapCollision

### Тест 2: Тонкая стена
1. Смотрите на тонкую стену
2. **Кубик появляется?** → Стена имеет коллизию
3. **Кубик пропадает при приближении?** → Проблема с толщиной меша

### Тест 3: Движение ракеты
1. Включите debug raycast (F3)
2. Выстрелите RPG
3. Сравните:
   - Где **кубик показывает коллизию**
   - Где **ракета взрывается**
4. Если не совпадает → проблема в RocketHeadObject.check_collision()

## Известные проблемы и решения

### Кубик не появляется:

**Причина 1:** Смотрите в пустоту
- **Решение:** Направьте камеру на стену/пол

**Причина 2:** mapCollision пустой
- **Решение:** Проверьте main.py - загружается ли карта?
```python
mapCollision.append(CollObject('Collision/map.obj'))
```

**Причина 3:** Файл карты не существует
- **Решение:** Убедитесь что `E:/python projects/ServerShooter/Collision/map.obj` существует

### Кубик появляется в неправильном месте:

**Причина:** Координаты Unity и сервера не синхронизированы
- **Решение:** Проверьте систему координат (Y вверх в обоих?)

### Кубик мигает:

**Причина:** Raycast попадает то в одну, то в другую поверхность
- **Нормально:** Это края полигонов

## Отключение после тестирования

Когда закончите тестирование:

**Вариант 1 (временно):**
- Нажмите **F3** в игре

**Вариант 2 (постоянно):**
- Снимите галочку `Enable Debug` в Inspector
- Или удалите компонент DebugRaycast

**Вариант 3 (удалить полностью):**
- Удалите файл `Assets/Code/Debug/DebugRaycast.cs`
- Удалите обработку пакетов из Client.cs (опционально)
- Сервер будет просто игнорировать пакеты

## Технические детали

### Сетевой протокол:

**CMSG_DEBUG_RAYCAST (45):**
```
float originX, originY, originZ      // Начало луча
float directionX, directionY, directionZ  // Направление
float maxDistance                    // Макс. дистанция
```

**SMSG_DEBUG_RAYCAST_RESULT (46):**
```
byte hit (0 или 1)                   // Есть попадание?
if hit == 1:
    float hitX, hitY, hitZ           // Точка попадания
```

### Производительность:

- **Частота:** 3.3 raycast/сек на игрока
- **Нагрузка:** ~10 пакетов/сек (туда-обратно)
- **CPU:** Минимальная (ray_object_intersection уже оптимизирован)

**Безопасно использовать** даже с 10+ игроками одновременно.
